# 《论语》十二章

高中语文课文《论语》十二章学习资料，选自《论语译注》（中华书局 2006 年版）。

## 课文结构

课文共十二章，节选自《论语》不同篇章：

- 《学而》：君子好学的标准
- 《八佾》：仁为礼乐之本
- 《里仁》：闻道、义利之辨、见贤思齐（三章）
- 《雍也》：文质彬彬
- 《泰伯》：士不可以不弘毅
- 《子罕》：为山一篑、三达德（两章）
- 《颜渊》：克己复礼为仁
- 《卫灵公》：一以贯之的"恕"道
- 《阳货》：《诗》的兴观群怨

## 使用建议

1. **课前**：阅读 `预习.md`，完成预习思考题。
2. **课中**：使用课文原文，结合译文与注释疏通文意。
3. **课后**：阅读 `价值.md`，思考传统文化的现实意义。
4. **拓展**：课文中的生图提示词可用于生成绘本插画，辅助教学展示。
